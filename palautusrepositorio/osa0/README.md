# Osa 0 – Web-sovellusten toiminnan perusteet

## Tehtävät
Tehtävät kuvaavat Sekvenssikaavion avulla käyttäen Mermaid-syntaksia mitä tapahtuu kun selain ja palvelin kommunikoivat keskenään, niiden kommunikointia on seurattu Chromen Dev Toolsin avulla.

#### 0.4: uusi muistiinpano
Kuvaa tilannetta, jossa käyttäjä lisää uuden muistiinpanon AJAX-tekniikalla toteutettuun muistiinpanojen listaan sivulle: https://studies.cs.helsinki.fi/exampleapp/notes.

#### 0.5: Single Page App
Kuvaa tilannetta, jossa käyttäjä menee selaimella muistiinpanojen SPA-version sivulle: https://studies.cs.helsinki.fi/exampleapp/spa.

#### 0.6: Uusi muistiinpano
Kuvaa tilannetta, jossa käyttäjä lisää uuden muistiinpanon SPA-tekniikalla toteutettuun muistiinpanojen listaan sivulle: https://studies.cs.helsinki.fi/exampleapp/spa.
