# Osa 5 - React-sovelluksen testaaminen, React Router

## Tehtävä
Tehtävässä luodaan React-sovellus Vite-työkalun avulla. Kielenä on JavaScript ja sen laajennus HTML:ää muistuttava JSX.

#### blogilistan-frontend
Sovellus jonka avulla rekisteröityneiden käyttäjien jotka ovat kirjautuneena, on mahdollista tallettaa tietoja Internetistä löytämistään mielenkiintoisista blogeista sekä nähdä muistissa olevat blogit ja niiden kirjoittajat. Sovellus käyttää käyttäjän tunnistamiseen tokeneita ja tallentaa onnistuneet kirjautumistiedot selaimen local storageen, kunnes hän kirjautuu ulos.
