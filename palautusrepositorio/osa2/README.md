# Osa 2 – Palvelimen kanssa tapahtuva kommunikointi

## Tehtävät
Allaolevissa tehtävissä luodaan React-sovelluksia Vite-työkalun avulla. Kielenä on JavaScript ja sen laajennus HTML:ää muistuttava JSX.

#### kurssitiedot
Viimeistelee jo osassa 1 aloitetun sovelluksen kurssitiedot, joka näyttää kurssin eri osien nimet ja tehtävämäärät. Uusina ominaisuuksina sovellukseen tulee esimerkiksi: kursseja voi lisätä ja poistaa, sekä sovellus laskee tehtävämääriä. Tapetilla oli erityisesti taulukon metodit kuten map() ja reduce(). Itse koen suurimpina oppimisasioina tästä JavaScriptin statement ja expression, niiden erot ja kuinka niitä voidaan käyttää eri osissa sovellusta (Javascript-osio v. JSX-osio/return). Sekä se kuinka dataa pallotellaan komponenttien välillä eri muodoissa (esim. olio vs. taulukko).
