# Osa 0 – Web-sovellusten toiminnan perusteet

## Tehtävät
Tehtävät kuvaavat Sekvenssikaavion avulla käyttäen Mermaid-syntaksia mitä tapahtuu kun selain ja palvelin kommunikoivat keskenään.

Kuvaa tilannetta, jossa käyttäjä lisää uuden muistiinpanon muistiinpanojen AJAX-tekniikalla toteutettuun versioon sivulle: https://studies.cs.helsinki.fi/exampleapp/notes.

#### 0.5: Single Page App
Kuvaa tilannetta, jossa käyttäjä menee selaimella muistiinpanojen SPA-version sivulle: https://studies.cs.helsinki.fi/exampleapp/spa

#### 0.6: Uusi muistiinpano
